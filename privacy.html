Policy

Privacy

Meridian is a client. It talks to the Letta server you configure. We do not run that server, and we do not sell your data.

Last updated 14 August 2026 · Operator: Oculair (oculairmedia)

Who this covers

This policy is for the Meridian Android and desktop apps published by Oculair. It is not a policy for Letta, Letta Cloud, or any server you point the app at. Those have their own terms.

What Meridian stores on your device

  • Connection details you enter (server URL, API keys, pairing secrets).
  • Local caches of conversations, agent lists, and similar data fetched from your server, so the app can work offline and feel fast.
  • Device pairing and sync state for multi-client live sync.
  • App preferences (theme, selected agent, and similar settings).

That data stays on the device unless you send it to a server you chose. Uninstalling the app deletes the local store, subject to OS backups you control.

What Meridian sends on the network

Meridian sends requests to the Letta endpoint you configure: a self-hosted server, Letta Cloud, or another compatible host. Chat messages, memory, agent configs, tools, and admin actions go there. We do not operate a Meridian backend that receives your chats.

The app may also contact GitHub to check for updates if you install from GitHub Releases or Obtainium. That is GitHub’s service, not ours.

What we do not collect

  • No advertising identifiers, no ads, no trackers.
  • No analytics SDK and no crash-reporting service in the current builds.
  • We do not sell personal information. We do not share it with data brokers.

Accounts and children

Meridian does not create its own user accounts. If you use Letta Cloud or another hosted server, that provider’s account and age rules apply. Meridian is not directed at children under 13.

Your choices

  • Use a self-hosted Letta server if you want the data to stay on machines you run.
  • Clear app data or uninstall to wipe the on-device cache and stored credentials.
  • Revoke API keys on the server if a device is lost.

Changes

If this policy changes, we will update the date on this page. Material changes will also be noted in the GitHub release notes.

Contact
