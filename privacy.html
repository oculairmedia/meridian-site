Privacy Policy

Effective 14 August 2026 · Meridian by Oculair

Meridian (“the app”) is a Letta-compatible client for Android and desktop, published by Oculair (GitHub: oculairmedia). This policy describes what the app stores, what it sends, and what it does not.

Meridian is a client. It is not Letta, and it is not a hosted agent service. You connect it to a Letta server you control or to Letta Cloud. That choice determines where your conversations and memory live.

Who this applies to

This policy covers the Meridian Android application and the Compose Desktop client built from the same project, including builds distributed via GitHub Releases, Obtainium, closed Play Store testing, and a future Play Store listing. It does not cover Letta itself, Letta Cloud, or any third-party MCP server, model provider, or tool you attach through your Letta server.

The short version

  • Chat, agent configuration, and memory stay on the Letta server you connect — your own instance or Letta Cloud.
  • The app keeps local caches, credentials, and device-pairing data on the device so it can reconnect and sync.
  • We do not show ads. We do not sell your data. We do not run a marketing pixel in the app.
  • Optional crash and performance reporting may be included in some builds. Chat contents and credentials are not intended to be part of that reporting.

Information you provide to your Letta server

When you use Meridian you authenticate to a Letta server (self-hosted or Letta Cloud) and then create, edit, and talk to agents; manage memory; and use admin surfaces (models, providers, tools, MCP servers, identities, folders, groups, schedules, jobs, runs).

That content is sent to the server you configured, not to Oculair as a product backend. We do not operate an Oculair chat or memory cloud that sits in the middle. If you use Letta Cloud, Letta’s own terms and privacy policy apply to data on that service. If you self-host, your own hosting and access controls apply.

Meridian needs network access to reach the server you name. It does not require that traffic to pass through Oculair.

Information stored on your device

To function, the app stores data in app-private storage on the device (and equivalent local storage on desktop), including:

  • Connection details and credentials — server URL and authentication material you enter so the app can sign in again.
  • Local caches — copies of conversations, agent metadata, memory fragments, and related records fetched from your server, used for offline-tolerant display and performance.
  • Device pairing data — identifiers and authorization material used for multi-client conversation sync and paired-device authorization between your own clients.
  • Preferences and UI state — settings you choose in the app.
  • Local crash summary — if the app crashes, a short record (timestamp, exception type, stack excerpt, optional crash event id) may be written on-device so you can see it on next launch. Dismissing it deletes that local record.

Uninstalling the Android app removes app-private storage. It does not delete data on your Letta server. Clearing desktop app data is under your control on that machine.

Crash and performance reporting

Meridian can include optional crash and performance reporting (Sentry). Reporting is initialized only when a project DSN is configured for that build. If no DSN is configured, reporting is not started and nothing is sent to Sentry.

When reporting is enabled, a crash or sampled performance trace may include:

  • stack traces and error messages generated by the app;
  • app version, operating system, and device model;
  • sampled performance traces and session health signals.

This telemetry is used to find and fix defects. It is not used for advertising. Chat messages, memory contents, and server credentials are not intended to be included. Events may be processed on Sentry infrastructure operated by Oculair (including a self-hosted instance).

We do not collect product analytics (no advertising identifiers, no usage funnels, no third-party ads SDKs). If that changes, this policy will be updated before it ships in a store listing.

Network and transport

You choose the destination. Typical endpoints are an https:// Letta server, Letta Cloud, or an iroh:// peer for paired-device sync. The app’s Android network config currently permits cleartext HTTP as well as TLS. Do not assume every off-device path is encrypted. iroh transport is used for live sync between clients you authorize; treat it as a separate path from HTTPS to your Letta server.

Oculair does not claim “encryption in transit” for Play Data safety while cleartext remains allowed and iroh encryption is not independently documented here.

Permissions and background work

The Play binary may request, and use when you invoke the matching feature:

  • Microphone — on-device speech input, only when you use that feature.
  • Camera — optional, currently for QR pairing / scan flows. The camera is not required to install the app.
  • Contacts and calendar — declared on Android so agents or tools you run can use them when you grant access. The core Letta-client loop does not require them.
  • Notifications and a notification listener — to surface assistant work and, where enabled, read notification context you allow.
  • Foreground service (remote messaging) — keeps chat push and the local embedded runtime alive while a session is active.
  • Network and boot-completed — to reach your server and resume after reboot if you have background sync enabled.

Android backup (allowBackup) is currently on, so OS backups may include app-private data on that device. We do not need your advertising ID. Call log is not requested.

How we use information we hold

Oculair uses device-local data only to run the client on your machine. If crash reporting is enabled in a build, we use those reports to maintain stability. We do not use Meridian data to profile you for ads or to sell lists.

Sharing

We do not sell personal information. We do not share your chat or memory with advertisers.

Data you send through Meridian is delivered to:

  • the Letta server you configured (including Letta Cloud if you choose it);
  • any model providers, tools, or MCP servers that your Letta server is set up to call — those are chosen in Letta, not by this client;
  • other Meridian clients you have paired (including over iroh://), for live sync and agent-to-agent messaging you enable;
  • Sentry, only when crash reporting is enabled in that build, as described above.

We may disclose information if required by law, or to protect the security of users, but the client architecture means Oculair typically does not hold your conversations in the first place.

Retention

Server-side retention is governed by your Letta server or Letta Cloud. Local caches and credentials remain until you sign out, clear app data, or uninstall. Local crash summaries remain until dismissed or overwritten. Crash reports that were actually uploaded are retained only as long as needed to debug, then according to our Sentry retention settings.

Children

Meridian is not directed at children under 13, and we do not knowingly collect personal information from children. If you believe a child has provided personal information through the app, contact us via GitHub and we will delete any such information we actually hold (typically limited to crash metadata, if any).

Your choices

  • Use a self-hosted Letta server if you want conversations and memory entirely under your infrastructure.
  • Revoke credentials and unpair devices in the app when you stop using a client.
  • Uninstall or clear app storage to remove local caches and credentials.
  • Delete agent, chat, and memory data on the Letta server you control, using Meridian’s management screens or the server’s own tools.

Security

Credentials and pairing material are stored in app-private storage. Prefer an https:// Letta URL. Cleartext HTTP is technically allowed by the current Android network config; use it only on networks you trust. You are responsible for the server you point Meridian at, including API keys and who can reach it.

International users

Oculair is the publisher of the client. Processing of crash reports, when enabled, may occur in the region where our Sentry instance is hosted. Chat and memory are processed wherever you host Letta or where Letta Cloud operates — that is outside this policy’s control.

Changes

If we change what the app collects — for example by turning on analytics in a store build — we will update this policy and the effective date. Material changes will be reflected on this page before those builds are offered as the current release.

Contact

Questions about this policy, deletion requests for data Oculair actually holds, or privacy reports:

  • GitHub organization: github.com/oculairmedia
  • Project issues: github.com/oculairmedia/letta-mobile/issues

There is no in-app advertising contact, and no separate marketing list. Do not send credentials or server tokens in a public issue; redact them.
