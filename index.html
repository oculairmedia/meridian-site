A client. Not the Letta app.

Meridian speaks Letta’s protocol. It is not Letta, not a fork, and not a hosted substitute. You bring the server. Chat, memory, and agent state stay there.

  • Your server

    Connect your own Letta instance or Letta Cloud. Meridian does not run your agents for you.

  • One domain module

    Kotlin Multiplatform. Android and Compose Desktop share a single domain layer; platform code stays thin.

  • By Oculair

    Built by oculairmedia. Source and releases live on GitHub.

What it does

The same capabilities on phone and desktop — agent work, memory, and the admin surface Letta already has.

Agent management
Create, edit, clone, import, delete, and organize agents on Android and desktop.
Rich chat
Tool outputs, code blocks, reasoning, mermaid diagrams, and a real-time assistant work timeline.
Interactive tools
AskUserQuestion and ExitPlanMode surface to you, with submit and approve wiring.
Memory administration
Core memory, archival passages, block library, and archive attachment flows.
Admin tooling
Models, providers, tools, MCP servers, identities, folders, groups, schedules, jobs, and runs.
Live sync
Multi-client conversation sync, paired-device authorization, and agent-to-agent messaging.
